## 一、本包改了什么

`wiki-ingest/scripts/check_delta.py` 中**纯本地**的同步状态机制整体退役：

- 删 CLI 四参：`--state` / `--write-state` / `--hash-map` / `--revision-map`。
- 删 `merge_state()`、`_cache_name()`、死常量 `DOC_TYPES`，以及 `main` 的 finalize 分支。
- 保留 `write_atomic()`（plan 输出 `--out` 仍用）、`classify()` 与 `--only` 及其 plan 侧拒绝守卫（rc=3）。
- 删本地文件 `feishu_sync_state.json` 与 `.gitignore` 忽略行；`feishu_sync_cache/` **未动**（有活读取方：`unchanged` 源正文来源）。
- 相应收口 6 份文档（`agents/pb-knowledge-steward.md`、`skills/wiki-ingest/SKILL.md`、`references/feishu-wiki-extraction.md`、`SYSTEM.md`、`workspace-layout.md`、`.gitignore`）。

**依据**：本包内该状态文件是「只写不读」——唯一读者是 `merge_state` 自身；判定一律取自远端索引（`AI_KB_INDEX_V1` 的 `source_edit_times` × 当前源 `edit_time_ms`），`classify()` 从不接 state 形参（有结构性回归锚钉着）。验收：四套回归 225/101/26/46 OK、两门禁不变、只读 dry-run 的 plan 与改动前一致（12/12 `preserve`）。

### 同日追加：N2 纯容器不再白下载（`f73cac3`）

- **快照 schema 新增字段** `char_count`（仅对 `has_child is True` 的容器节点填；代理预检期用轻量 profile `docs +script --command parse` 取 `data.profile.char_count`，回包约 320 B、不含正文）。
- **DELTA 行新增条件段** `/ pure_containers N`（仅 N>0 时出现）。
- `check_delta` 把 `char_count < 200` 的容器单列 `pure_containers` 且**不计入 `process`**；取不到/非整数/≥200 一律照常下载（fail-safe）。阈值常量 `PURE_CONTAINER_MAX_CHARS = 200`。
- **对侧影响**：若对侧 `check_delta.py` 由其镜像，需同步该字段与 DELTA 段；不镜像亦不破坏远端契约（仍是纯本地文件）。

### 同日追加：B1 候选页来源版本时效核对（`3a0cf70`）

- `generate_entries.py --validate-only` **新增必需参数** `--nodes <_nodes_snapshot.json>`：逐候选页逐源比对 `source_edit_time_parts` 与本轮快照 `edit_time_ms`，**不等即 FAIL（不发布）**；核对不了的情形只判 WARN。缺 `--nodes` 或快照不可读 ⇒ **rc=2 fail-closed**。
- **对侧影响**：若对侧复制了 `generate_entries.py` 或 SKILL Step 6.5 的命令行，需同步加该参数——**这是硬接口变更**（旧调用会 rc=2 硬停，不静默跳过），对侧若沿用旧命令会在 Step 6.5 直接失败；这属**有意**（fail-closed），但需对侧知晓并在同一批更新其调用点。
- 另：SKILL Step 3 加了「先读 Step 4」前向指针；Step 6 加了 staging 中间态免责句——均纯文档，无接口影响。
