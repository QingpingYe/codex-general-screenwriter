# In Create Baseline

## Medium Routing

### picturebook

创作前读取 `../text-craft/SKILL.md` 及相关引用：

- `craft-principles.md`
- `technique-cards.md`
- `craft-baselines.md`

### shortdrama / tv_longform

读取选中类型包声明的创作结构、episode/hook/scene/beat 约束和权威引用；当类型包未声明工艺文档时，直接使用类型包阶段与产物契约，不假设页数、翻页节奏或绘本工艺规则。

## Structure Gate

写正文前必须先确定：

1. 产物类型
2. 叙事母弧线或结构骨架
3. 关键情感落点
4. 长度或单元数量约束
5. 禁止事项和权威边界

任一项缺失时，先回问用户或读取权威知识，不得先写后补。

## Boundary Card

把权威知识中的硬约束整理为：

```markdown
## 边界卡

- 世界观：
- 角色边界：
- 数值约束：
- 禁止事项：
```
