# Novel to Short Drama Adaptation

## Input

先收集最小可用输入：

1. 小说文本或可改编素材，标明可用的卷、章、人物关系和结局走向。
2. 改编目标：预计集数、单集时长、平台、受众分级和题材。
3. 观看动机：爽感、悬疑、情感、复仇、逆袭、身份反差或关系张力。
4. 系列约束：世界观边界、人物上限、主线长度、敏感内容边界和可否改变结局。
5. 当前集范围：要改编的章节、事件或情绪节点。

若素材过长，先做“事件账本”：每章只记录动机、冲突、转折、代价、状态变化和伏笔。不要照抄章节顺序；按短剧追更逻辑重组事件。

## Method

### 1. 收束小说母题

从素材中提取一个可复述的改编主命题：谁在什么限制下追求什么，代价是什么，为什么观众会期待下一集。删去只服务文字叙事的说明段，保留能外化为动作、选择、误认、反制或关系变化的事件。

### 2. 建立人物引擎

每集保留 1-3 个可行动的主要人物。为每个人物定义欲望、限制、手段、秘密和与主角的关系压力。改编时合并功能重复的人物，把内心独白转为谈判、试探、谎言、公开反制或选择代价。

### 3. 映射事件到集

一集承载一个可命名的问题和一次状态翻转。可用序列：

1. 悬置问题：把上一集后果变成新的压力。
2. 主动选择：主角或对手采取有风险的动作。
3. 意外反馈：信息、关系或资源发生变化。
4. 局部胜利或代价：不能只是情绪反应，必须改变局面。
5. 新钩子：揭示更深的秘密、更大的威胁、更近的距离或更急的期限。

### 4. 设计钩子

每集至少设计三级钩子：

- 开场钩：前 10 秒承接上集后果，立刻给出视觉冲突或追问。
- 中段反转：在观众形成临时判断时加入新证据、误认或利益交换。
- 结尾钩：留下未完成的行动、身份揭示、威胁逼近或关系破裂。

钩子必须由已知信息升级而来，不靠强行失忆、无动机巧合或重复误会。

### 5. 展开节拍与场景

先把每集拆成 8-15 个节拍，每拍写清目标、阻碍、动作、信息和变化。再聚合成场景：每个场景只保留一个主要目的，以“进入时关系/信息状态、压力动作、离开时变化”三段推进。删去不改变信息的寒暄、风景和重复情绪。

### 6. 改写台词

台词要短、可说、有目的。每句至少完成一个任务：推进冲突、揭示动机、交换条件、误导对方或改变关系。把说明性独白改为对方追问、公开拒绝、条件交换或沉默后的动作。关键反转前让人物说错一半，行动说另一半。

## Episode / Hook Structure

单集骨架：

1. Cold Open：上一集代价直接落到人物身上。
2. Pressure：目标具体化，限制收紧。
3. Move：主角或对手作出可观察的选择。
4. Turn：新信息或新后果改变局势。
5. Settlement：本集问题得到局部结果。
6. Cliffhanger：抛出下一集必须处理的问题。

集与集之间维护三条连续线：

- 主线：核心追求和最终对抗。
- 关系线：信任、误会、依附、背叛或亲密程度。
- 威胁线：对手能力、时限、暴露风险和资源消耗。

## Output Format

按阶段输出可交接产物：

1. `episode_outline`：每集写母题、问题、人物目标、关键选择、状态变化、伏笔和结尾钩。
2. `hook_sheet`：列出开场钩、中段反转、结尾钩，并注明对应节拍、证据来源和下集后果。
3. `beat_sheet`：按顺序列节拍、 POV、目标、阻碍、动作、信息变化和情绪强度。
4. `scene_table`：每场记录地点、时间、人物、进入状态、冲突动作、离开变化、连续性备注。
5. `episode_script`：使用短剧剧本格式，场次、场景描述、人物动作和台词分明；每场只保留改变局面的信息。

如果输入跨多集，先给系列事件账本，再输出本集五件套。

## Checkpoints

产出前逐项检查：

1. 改编命题能否一句话复述，且与小说母题一致。
2. 每集是否只有一条主行动线，钩子是否来自既有信息升级。
3. 主要人物是否主动行动，而不是被剧情推着反应。
4. 每个场景是否改变信息、关系或资源状态。
5. 台词是否去掉重复说明，冲突是否有具体代价。
6. 连续性是否核对：时间、地点、伤势、财物、知情范围、承诺和威胁。
7. 题材、受众和平台约束是否未被越过。

任何一项失败，回到对应节拍或场景重写，不要用台词解释缺口。
